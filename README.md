# Aplicativo do Líder

Aplicativo Flutter para gerenciamento de grupos, membros, reuniões e chamadas.

## Executar localmente

```sh
flutter pub get
flutter run
```

## Gerar APK Android de release

```sh
flutter build apk --release
```

O APK é gerado em `build/app/outputs/flutter-apk/app-release.apk`.
